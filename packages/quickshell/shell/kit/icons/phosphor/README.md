# Phosphor icons

The SVG files in this directory are bundled locally from Phosphor Icons.

- Project: https://phosphoricons.com/
- Source: https://github.com/phosphor-icons/homepage/tree/master/public/assets/phosphor.iconjar/icons
- License: MIT
- Variants: the plain `.svg` file is the regular/outlined weight; `-fill.svg` is the filled weight.

The shell recolours the glyphs at render time. Do not add network requests for icon loading.

# Визуальный стиль

Все значения ниже уже заложены в `templates/remotion/src/theme.ts` и `styles.ts`. Менять — там, не в сценах.

## Общее

- 60 fps, 1920×1080 базово. 4K рендерится из той же композиции со `scale=2` только если исходники ≥ 1440p.
- Шрифт: Inter (через `@remotion/google-fonts`, сабсеты latin + cyrillic). Вес подписи 600–700, подзаголовка 400–500.
- Трекинг крупного текста отрицательный: −0.03em на 96px+, −0.02em на 64px.
- Экран в режиме `float`: скругление 18px, тень `0 40px 120px rgba(0,0,0,.55)`, ширина 82% кадра.
- Наезды только ease-in-out (`Easing.bezier(0.45, 0, 0.2, 1)`), без линейных.
- Переходы между сценами: `fade` 12–18 кадров. Жёсткая склейка — только в ритм-блоке.

## apple

| Параметр | Значение |
|---|---|
| Фон | `#000` (или `#fff` для светлой оболочки) |
| Текст | `#f5f5f7`, подзаголовок `#86868b` |
| Акцент | один цвет из палитры оболочки — только для одного слова в титре |
| Подпись | 112px / 700, появление: blur 20px→0 + opacity + y 24px→0 за 24 кадра |
| Подзаголовок | 40px / 500, задержка 10 кадров |
| Клип | наезд 1.00→1.25 max, длительность наезда = длительность сцены |
| Музыка | тихий старт, без дропа в первые 10 с |

## fluent

| Параметр | Значение |
|---|---|
| Фон | анимированный mesh-градиент из 3 цветов палитры, медленный дрейф (период 8 с) |
| Карточка подписи | acrylic: `rgba(255,255,255,.12)`, `backdrop-filter: blur(40px) saturate(1.6)`, граница 1px `rgba(255,255,255,.18)`, скругление 24px |
| Подпись | 96px / 600, градиентный текст из 2 акцентов |
| Появление | spring (`damping: 14, mass: 0.8`) по scale 0.92→1 + opacity |
| Клип | экран слегка наклонён (`rotateX 6deg` → 0) при входе |

## Чего не делать

- Больше двух анимаций одновременно на одном объекте.
- Подписи поверх активной зоны клипа (виджета, на который наезд).
- Зум > 1.25 на 1080p-исходнике, > 1.6 на 4K.
- Эмодзи, восклицательные знаки, стоковые иконки в титрах.

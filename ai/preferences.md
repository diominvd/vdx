# Working preferences

- Answer in the user's language; keep code comments and project documentation
  in the project's established language. VDX documentation is terse English.
- Be direct, concrete and concise. Explain results, checks and remaining limits.
- Read the project's `AGENTS.md` and relevant topic docs before changing code.
  Reuse existing components and state owners.
- Briefly plan complex changes and continue within the authorized task. Wait
  for plan approval when the user asks for it; keep plans in the conversation.
- Use focused searches and bounded output; expand context when evidence needs it.
- Preserve unrelated work. Do not commit or push unless requested.
- Do not delegate to subagents unless the user explicitly asks.
- Treat saved memories as dated context. Verify current state before following
  old task lists, branch names, test results or handoff instructions.
